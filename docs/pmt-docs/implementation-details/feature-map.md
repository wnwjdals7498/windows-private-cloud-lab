# 원래 작업과 책임 카드 연결

145개 원래 작업은 각각 하나의 주 책임 카드에 연결된다. 같은 작업이 다른 카드의 선행·통합 시험에 나오는 것은 중복 소유가 아니다. 실호스트 순서는 기존 선행 조건을 그대로 따른다.

## 해석

- 카드 완료는 원래 선행 증거를 모두 충족할 때만 인정한다. 코드 단위·fixture 검증만 끝났다면 준비 수준으로 보고한다.
- 조건부 기술·환경 선택은 원래 G 게이트를 따른다. 외부 Cloud 결과는 X 인계가 실제 준비되기 전 완료로 간주하지 않는다.
- S12는 내부 자원 변경 개발을 나눌 수 있지만 P15-10의 전체 충돌 검증에는 S11의 삭제 결과도 필요하다.
- O08 이후 운영 카드도 실제 인수는 기존 P16/P17 순서를 따른다. 공통 정책·계측의 독립 개발은 앞당길 수 있다.
