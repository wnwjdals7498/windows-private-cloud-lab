# Windows 사설 클라우드 UI 가이드 · 초안

> 최신 배치에서는 이 화면을 **Linux 관리자 콘솔**에 통합한다(PMT D47). 아래 PHP 배치 설명은 이전 이력이며, 구현 범위는 [상세 계획](../implementation-plan.md)의 P16·X04를 따른다.

> 실습 절차와 결과를 읽기 쉽게 보여주는 화면 설계 문서. [HTML 목업](mockup.html)은 가상 데이터만 사용한다. 실제 화면은 별도 Windows 웹앱이 아니라 PHP·CodeIgniter 관리포털의 관리자 메뉴에 넣는다.

## 화면 목표

- **호스트 상태 → VM 상태 → 실행 절차 → 검증 기록** 순서로 읽힌다.
- 단일 Windows 11 Pro Hyper-V 호스트라는 시험 범위를 항상 명시한다. 화면에 클러스터 장애 내성을 암시하지 않는다.
- 포털의 VM 신청과 Hyper-V 작업을 연결하되, 이 화면은 운영자용 실습·검증 화면으로 설계한다.
- 실행 전 조건과 실행 후 결과를 구분한다. 요청 접수와 VM 생성 완료는 다른 상태다.

## 정보 구조

| 메뉴 | 핵심 내용 |
| --- | --- |
| 개요 | 호스트 가용 자원, VM 수, 최근 작업, 실습 단계 |
| 가상 머신 | VM별 상태·사양·스위치·마지막 동기화 |
| 자동화 | PowerShell 작업 정의, 실행·실패·재시도 기록 |
| 검증 기록 | 수동 작업과 자동화 결과 비교, 증거, 장애 범위 |
| 환경 점검 | CPU·메모리·저장공간·가상화·네트워크 확인 |

## 시각 규칙

- PHP 포털과 동일한 밝은 배경·남색 탐색·파랑 주요 동작을 사용한다.
- 자원 사용량은 숫자와 막대가 함께 나타나게 한다. 막대만으로 상태를 표현하지 않는다.
- 상태는 정상(청록), 실행 중(파랑), 주의(주황), 실패(빨강), 미실행(회색)으로 구분한다.
- 실습 단계는 순서와 완료 조건을 함께 표시하고, 미실행 단계는 완료처럼 꾸미지 않는다.
- 본문 14px 이상, 버튼 높이 40px 이상, 키보드 포커스 표시, 좁은 화면의 가로 스크롤을 제공한다.

## 핵심 화면

1. **호스트 개요:** Hyper-V 사용 가능 여부, 자원 여유, 가상 스위치, VM 현황과 마지막 확인 시각.
2. **VM 상세:** 실제 상태, CPU·메모리·디스크, 연결 스위치, 포털 요청 ID와 작업 결과.
3. **자동화 작업:** 입력값, 실행 단계, 시작·종료 시각, 실패 지점, 재시도와 복구 기록.
4. **검증 기록:** 수동 생성과 PowerShell 결과의 비교, 삭제·복구 재현, 사용 환경의 한계.

## 공통 컴포넌트

- **작업 타임라인:** 요청, 준비, 실행, 확인, 완료/실패를 순서대로 표시한다.
- **상태 배지:** 색과 텍스트를 함께 표시하고 실제 Hyper-V 상태와 일치시킨다.
- **위험 동작:** 삭제·재시작은 VM 식별자와 영향을 재확인한다.
- **근거 링크:** 공개 가능한 로그와 절차 문서를 연결한다. 실제 IP·계정·토큰은 표시하지 않는다.
- **시간:** Asia/Seoul 기준 시각과 마지막 동기화 시각을 명시한다.

## 구현 전 확인

실제 호스트에서 읽을 수 있는 지표, PowerShell 작업 단계, 포털 요청과 결과의 연결 키, 장애·복구 증거 형식을 먼저 확정한다. 목업의 수치와 실행 기록은 검증 자료가 아니다.
